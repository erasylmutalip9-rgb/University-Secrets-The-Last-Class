# v0.11 / изменения к v0.10

Сохранена существующая рабочая v0.10: 20 сцен, первая глубокая карта, её правила
и концовки. Новая версия создаётся из распакованного архива без переписывания
движения, рендера и систем прохода.

- scripts/campaign/controller.gd: главное меню; магазин, макет донат-образов;
  19 экспертиз, понятная обратная связь; пять жестов; статус и предпросмотр;
  одноразовое голосовое распознавание через Python.
- scripts/investigation/controller.gd: голосовой вопрос на уровне 1, выключение
  прослушивания при закрытии допроса.
- scripts/game.gd: общая кнопка 🎤 в диалогах NPC и запуск AI без CMD через pyw.
- scripts/campaign/map.gd: расположение улик на разных сторонах карты,
  отдельная 3D-станция «ЭКСПЕРТИЗА» с физической коллизией.
- scripts/campaign/state.gd: новые цели и сброс этапа экспертизы при повторе;
  совместимость ранее сохранённых flags/evidence.
- data/casework.json: 19 авторских сценариев мини-расследований для карт 2–20.
- ai_service/gesture_service.py: 5-й жест Pointing_Up, JPEG-кадры в игре,
  переподключение камеры, поиск индексов 0–2.
- ai_service/launch_camera.py: автоматическая разовая подготовка зависимостей
  и модели, журнал процесса при запуске без консоли.
- ai_service/voice_service.py, voice_windows.ps1, setup_voice.py и Windows .bat:
  распознавание русских вопросов и опциональная офлайн-модель Vosk.
- EXPORT_WINDOWS.bat: копирование голосовых вспомогательных файлов.
- tests/test_v11_extensions.py: проверки совместимости содержимого и интерфейса.

Важно: новый контент улучшает уровни 2–20, но **не делает их настолько же
глубокими, как ручной сценарий уровня 1**. Для достижения этого нужны отдельные
сцены, новые диалоги, катсцены и ручные тесты. Не называем проект идеальным.

**Достоверность проверки:** Python и структура проверяются в среде сборки;
Godot и физические устройства Windows здесь не доступны.
