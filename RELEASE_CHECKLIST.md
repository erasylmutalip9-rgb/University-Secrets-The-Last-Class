## Экспорт Windows

1. Godot 4.6.3 Standard → `Project` → `Export`.
2. `Manage Export Templates` → установить шаблоны соответствующей версии движка.
3. Добавить **Windows Desktop** (можно использовать имеющийся `export_presets.cfg`).
4. Выбрать `Export Project`, а не `Export PCK/ZIP`, указать `dist/Tayny_Universiteta.exe`.
5. Если у проекта рядом с `.exe` появился `.pck`, **не отделяйте их**. ZIP должен содержать оба файла; если Godot встроил PCK в EXE, достаточно исполняемого файла.
6. Откройте ZIP на другой машине без редактора Godot. Полностью пройдите сценарий, а не только меню.
7. При желании используйте `EXPORT_WINDOWS.bat`, если Godot CLI и Export Templates уже установлены. Скрипт не создаст EXE без шаблонов экспорта.
