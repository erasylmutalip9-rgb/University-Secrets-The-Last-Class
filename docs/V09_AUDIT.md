# Аудит перед переработкой

v0.9 уже содержала20 отдельных сцен, таблицу целей, магазин/сохранения/повтор, прежние камеры и NLP, жестовую реконструкцию и финалы. Это пригодная основа, которую не следует заменять пустым новым проектом.

Проблема: общий цикл «подойти к предмету → E → станция с вариантами → выход» доминировал на картах. Различия окружения не создавали достаточного различия действий. Неправильный ответ позволял повтор, но объяснял мало. Документ/запись нередко собирались одинаково; глубокая манипуляция предметом и проверка цепочки доказательств отсутствовали.

Решение этой итерации: новый controller поверх существующего, только специальный двор; rules отделены от UI. Все20 сцен не переписаны массово. Для остальных карт составлен сценарий с разными центральными механиками. Установка настоящего AI-сервиса не заменялась заглушкой; его физический запуск остаётся отдельной приёмкой.

Не выдавать число сцен за число глубоких уровней. Не выдавать автотест маршрута за8–15мин живого расследования. Не выдавать ввод заметки за семантический анализ мысли игрока. Не выдавать процедурные модели за финальную графику.
