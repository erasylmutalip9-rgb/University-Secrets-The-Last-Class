# Ручная приёмка Windows — NOT RUN

Для каждого из Level01–Level20: проверить FPS и TPS, объекты на опоре, освещение,
читаемость HUD/диалогов, проходы между мебелью, невозможность пройти сквозь стены,
E у каждой улики, открытие шкафов, отказ выхода до целей и переход после целей.
Вписать фактические PASS/FAIL, дату, Godot, GPU, разрешение и описание дефекта.

Особые проверки:
- Новая игра в трёх сложностях; easy показывает отметки, hard ограничивает H.
- На 11 попытаться взять USB до кода, затем открыть шкаф.
- На 13 спросить Миру о копии; 14 Руслана о камерах; 15 Данияра о пропуске;
  20 Данияра об удалении. Флаги появляются только при нужных уликах.
- Сохраниться при открытом шкафе, выйти из процесса, загрузить: предметы/покупки на месте,
  игрок у безопасного входа. Проверить кириллический путь профиля Windows.
- Купить куртку/рюкзак/часы/фонарь/журнал/доску/скейт: проверить внешний вид через V.
  Скейт ускоряет только во дворе. Повторно надеть без списания.
- Повторить завершённую карту, отменить повтор через M: прежний баланс и прогресс вернулись.
- На 19 проверить неверный и верный порядок мышью, затем реальные 4 жеста.
  Отключить камеру посреди задачи: продолжить мышью.
- Проверить четыре концовки повтором 20 уровня, секретный флажок включить/выключить.
- Отключить резкие эффекты, проверить архив Алекса без скримера и тряски;
  проверить ползунок громкости после перезапуска.
- Установить Ollama/gemma3:4b отдельно, проверить доступный/недоступный сервис.
- Экспортировать Windows. Пройти на второй машине без редактора.

Таблица для заполнения: ID / действие / ожидается / факт / PASS-FAIL / дата / тестировщик.
Не отмечать тест по одному HTTP 200 или нажатию кнопки без реального кадра.
