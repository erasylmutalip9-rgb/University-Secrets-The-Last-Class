# Тайны университета: Последняя пара — 3D v0.8

3D-детективный триллер для Windows. Учебный проект РК2, **IT Project Game Challenge 2026**.

**Авторы:** Мухит Меруерт и Муталип Ерасыл, группа ИС-44. Движок: Godot 4 (рекомендуется 4.7.2, как на компьютере команды). Python нужен только для модуля реального жестового распознавания.

## Статус

v0.8 — исходный проект-кандидат для проверки. Пользователь подтвердил, что предыдущую версию можно пройти, но сообщал о проблемах визуала и камеры. Здесь переработаны основные материалы, свет, модели, движение и запуск жестов. **В Godot 4.7.2 и на веб-камере пользователя эта версия ещё не проходила реального тестирования. Не публикуйте её как окончательный релиз, не проверив полностью.**

## Запуск в Godot

1. Распакуй архив в отдельную папку, **не поверх старой v0.7**.
2. В Godot нажми `Import` и выбери `project.godot`.
3. Дождись импорта текстур и нажми **F5**.
4. На экране `Новая игра` прочитай вступительную инструкцию.
5. Дойди до архива, пройди головоломку и финальное обвинение.

## Управление

| Клавиша | Действие |
|---|---|
| WASD/стрелки | Идти |
| Shift | Бежать |
| Пробел | Прыгать |
| Мышь | Осмотреться |
| E | Взаимодействовать с предметом, открыть шкаф/взять улику, поговорить |
| V | 1-е / 3-е лицо |
| R | Выравнять камеру |

| Esc | Пауза |

Движение стало более плавным: есть ускорение и торможение. Не все декоративные предметы интерактивны. Для некоторых папок нужно дважды нажать E: открыть шкаф, затем забрать предмет.

## Маршрут игры

Вестибюль → налево в библиотеку → найди три сюжетных документа → получи доступ в лабораторию → исследуй пропуск, место происшествия и флешку → используй станцию анализа → архив → собери хронологию → обвини подозреваемого и предъяви факты.

Игра сохраняет прогресс, 12 улик, допросы, сюжетные ветви и разные концовки. По H можно снова открыть подсказки.

## AI

**AI №1: локальный классификатор вопросов.** В `scripts/intent_classifier.gd` находится модель Naive Bayes, обученная различать категории вопросов на русском языке. Она влияет на ответы NPC и расследование и работает без Python.

**AI №2: распознавание жестов MediaPipe.** В архиве при взаимодействии с доской хронологии игра теперь **сама запускает** `START_GESTURES_AUTO_WINDOWS.bat` (если используется Windows). Скрипт автоматически проверяет/устанавливает зависимости при необходимости, загружает модель и пытается открыть веб-камеру. Первый запуск требует интернета и Python с командой `py -3`.

Кадры не уходят в облако. Подробная инструкция и устранение ошибок: `GESTURES_SETUP.md`. **Журнал диагностики:** `ai_service/camera_diagnostics.txt` — он теперь есть уже в архиве и перезаписывается при каждой попытке запуска. При неуспехе жестового AI головоломку можно пройти мышью; мышь не считается распознаванием жеста.

Генеративные диалоги через Ollama (`gemma3:4b`) — **необязательный экспериментальный режим**. Виртуальный сканер улик — игровая имитация, не настоящая CV-классификация карточек.

## Что улучшено в v0.8

- Вместо пересвеченных комнат — более сдержанный тёплый интерьер и направленный свет, без цветного неона.
- Рендер переключён с OpenGL Compatibility на **Forward+** (Vulkan/Direct3D 12) с SSAO. На слабых компьютерах можно изменить Renderer в настройках проекта обратно на Compatibility, но картинка будет другой.
- Шесть новых оригинальных текстур с картами нормалей; более выраженные фактуры дерева, камня, плитки, стен и мебели.
- Исправлен баг, из-за которого все комнаты могли использовать одну и ту же текстуру через общий кэш материалов.
- Новая модельная система персонажей: вместо наборов оторванных капсул — более цельные трубчатые меши и сглаженные формы лица/одежды.
- Плавная инерция ходьбы, бега и торможения, уменьшенные прыжки.
- Автоматический запуск реального MediaPipe при головоломке и постоянный лог диагностики.
- Крупные столы получили физические препятствия; сохранена защита от провалов.

Модели пока **не фотореалистичные** и не имеют полноценного скелетного рига. Чтобы достичь визуального качества современной коммерческой 3D-игры, в будущем потребуется заменить их лицензированными rigged GLB персонажами и профессиональными объектами окружения. Без таких ресурсов нельзя честно обещать качество GTA.

## Где код

- `scripts/game.gd` — сюжет, цели, GUI, инвентарь, взаимодействия, сохранения и AI-мост.
- `scripts/player.gd` — физика, плавное движение, первый/третий вид, прыжок.
- `scripts/world_builder.gd` — комнаты, стены, коллизии, мебель, улики.
- `scripts/character_visual.gd` — процедурные 3D-модели персонажей и их движения.
- `scripts/intent_classifier.gd` — модель AI-классификации вопросов.
- `ai_service/gesture_service.py` — настоящая модель MediaPipe.
- `ai_service/launch_camera.py` — автозапуск с записью диагностического отчёта.
- `tools_generate_pbr.py` — генерация фактур и карт нормалей.

В Godot открой снизу `FileSystem` → `scripts` → дважды щёлкни `.gd`. Во время F5 можно в Scene переключить `Локальный` на `Удалённый` для просмотра объектов запущенной игры.

## Windows-релиз и itch.io

Это **проект исходного кода**, не исполняемая игра `.exe`. Для сдачи РК2 нужно создать экспорт через Godot: Project → Export → Windows Desktop → установить Export Templates → Export Project. Или выполнить `EXPORT_WINDOWS.bat` при наличии Godot в PATH. Сборка будет в `dist`, вспомогательные Python-файлы тоже копируются туда. Упакуй **всю папку dist** в ZIP, затем протестируй без Godot на другом компьютере. Только после этого публикуй на itch.io.

Известное системное замечание: если Godot выдаёт ошибки WASAPI, это связано с устройством звука Windows. Проверь активное устройство воспроизведения; сам файл проекта здесь не определяет драйвер Windows.

## Проверки

Скрипты `tests/check_project.py`, `tests/quality_gate.py`, `ai_service/test_gestures.py` проверяют структуру и отдельные алгоритмы, но **не заменяют реальное прохождение и проверку камеры**.

## Если игра считает все обвинения ошибочными (фикс v0.8.2)
Виновный в канонической истории — Данияр. Для победы нужны не только улики, но и разговор с ним: после нахождения журнала пропусков в лаборатории спроси его о пропуске или входе в 21:17. Затем найди след, историю правок в архиве и восстанови хронологию. При недостатке фактов игра теперь подсказывает, что осталось, вместо ложного экрана «Ошибочное обвинение».
