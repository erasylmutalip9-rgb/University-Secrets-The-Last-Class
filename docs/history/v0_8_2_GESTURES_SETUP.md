# Как работает камера / жесты в версии v0.8

Теперь **не нужно запускать камеру вручную заранее**. Если у тебя Windows и установлена программа запуска Python `py`, игра сама откроет сервис при входе в головоломку **«Реконструкция хронологии»** в архиве. Веб-камера открывается через OpenCV, жесты распознаются обученной моделью MediaPipe локально.

При первом запуске камера может появиться не сразу: система попробует установить библиотеки и загрузить официальную модель (необходим интернет). Игра остаётся проходимой мышью, если этот процесс не удался.

## Проверка с нуля

1. В настройках Windows → Конфиденциальность и безопасность → Камера включи разрешение приложениям рабочего стола.
2. Закрой Telegram, Discord, Zoom, OBS или другие программы, использующие камеру.
3. Убедись, что Python установлен: в PowerShell `py -3 --version`.
4. Для предварительной установки запусти `SETUP_CAMERA_WINDOWS.bat` (необязательно, но лучше сделать до защиты).
5. В Godot запусти игру (F5). Дойди до архива, собери E04, E08, E12 и открой стенд хронологии (`E`).
6. Отдельная программа запустится автоматически. Покажи жест около секунды, затем измени его или убери руку.
7. На экране головоломки должны появиться название распознанного жеста и уверенность классификатора.

Жесты: **кулак** = кнопка 1, **Victory** (два пальца) = кнопка 2, **ладонь** = кнопка 3, **лайк** = кнопка 4. Действия головоломки выбираются по расположению кнопок. Важен правильный порядок событий, а не число пальцев.

## Если камера не запускается

**Файл отчёта всегда есть в новой папке:** `ai_service/camera_diagnostics.txt`. До первого запуска он содержит текст «Camera has not been started…», после запуска перезаписывается полным журналом работы Python, установки MediaPipe и запуска модели.

1. Открой этот файл после попытки автозапуска.
2. Если журнал всё ещё содержит начальный текст, вручную запусти `START_GESTURES_AUTO_WINDOWS.bat`: тогда будет видно, почему из Godot не стартует отдельный процесс.
3. Если сообщение `Missing modules` или `INSTALL FAILED`, запусти `SETUP_CAMERA_WINDOWS.bat` с интернетом.
4. Если `Камера 0 ... не открылась`, выполни `CHECK_CAMERA_WINDOWS.bat`: может потребоваться индекс 1 или 2 и изменение настроек камеры.
5. Если `Could not resolve host` — компьютер не скачал модель при первом запуске; подключи интернет.
6. При желании можно проверить без игры: открой `http://127.0.0.1:8765/gesture` в браузере. В настоящем AI-режиме должно быть `"active":true, "mode":"webcam", "status":"ready"`.

**Важно:** ввод цифр в старом резервном скрипте — НЕ распознавание жестов и НЕ засчитывается как AI. Для РК2 реальный MediaPipe нужно показать с настоящей веб-камерой. Если он не заработает, игра всё равно содержит отдельную ML-механику: классификатор вопросов NPC (Naive Bayes).

## Для экспортированной Windows-версии

В ZIP для itch.io должны быть вместе: `Tayny_Universiteta.exe`, файл `.pck` (если не вшит), папка `ai_service` и `START_GESTURES_AUTO_WINDOWS.bat`. Скрипт `EXPORT_WINDOWS.bat` автоматически копирует эти файлы в `dist`, но сам экспорт требует установленного Godot и Export Templates.
