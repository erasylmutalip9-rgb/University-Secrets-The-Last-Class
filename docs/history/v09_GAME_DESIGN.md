# GAME DESIGN / v0.9

> Документ для разработчиков: содержит спойлеры.

Канон сохранён: виновник Данияр. Фальсификация → угроза разоблачения → конфликт
с профессором и травма → попытка удаления данных. Мира скрыла настоящую копию,
Руслан скрыл уход с поста и неоформленную диагностику. Алекс — участник ЭХО.
События: 21:08 OFF; 21:17 вход; 21:22 конфликт/травма; 21:26 удаление; 21:36 ON.
Начало: Алекс прибывает вечером следующего дня; никто не знает виновника заранее.

На каждой карте обязательна также challenge_N — станция проверки версии.
Карты 2/7 требуют вопрос свидетелю; 13/14/15/20 — содержательной проверки улик.
Карта 11 блокирует носитель до кода шкафа; 19 требует порядок пяти событий.
Основные 20 карт бесплатны. Монеты покупают только внешний вид/транспорт во дворе.

Сложность: easy — отметки и объяснение ошибок; normal — помощь H по запросу;
hard — дополнительная проверка источника, 3 подсказки и необязательный бонус за 45с.
Таймер не блокирует обязательные цели. Отвлекающие версии представлены вариантами
ответов; отдельные физические ложные улики ещё не реализованы.

Четыре исхода: correct, wrong, unresolved, secret. Правильное обвинение проверяет
message/motive, pass/security, trace/injury, audit/usb, timeline_solved,
danyar_contradiction и danyar_coverup. Недостаток улик не считается ошибочным именем.
Секретный эпилог требует также alex_file, old_photo, mira_backup, guard_report.
Его можно не раскрывать, чтобы получить обычную правильную концовку.

Допросы и пропуск мира контролируются кодом, а не произвольным ответом LLM.
Каталог кампании не показывается целиком игроку; неизвестные материалы скрыты.
