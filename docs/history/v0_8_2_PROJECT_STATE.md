# Состояние проекта: v0.8 — проверочная сборка

**Проверено в среде подготовки:** структура проекта, пути ресурсов, 137 статических проверок и 49 проверок дополнений, 3 Python-теста обработки жестов. Это не равно тестированию в Godot.

**Рабочее прохождение:** пользователь подтвердил прохождение более ранней версии (v0.4/v0.5), а в версии v0.7 сообщил о слишком ярком освещении, пластмассовых персонажах и неработающих жестах. Эти недостатки и были главным предметом v0.8. **Полный проход новой версии пользователем ещё не подтверждён.**

## Реализовано для проверки
- сохранён маршрут: вестибюль → библиотека → лаборатория → архив → обвинение, 12 улик, несколько концовок;
- переработано освещение: более тёмное нейтральное, без неона; Forward+ + SSAO на совместимых GPU;
- сгенерированы авторские текстуры пола и стен с картами нормалей;
- исправлена ошибка общего материала для разных комнат (материалы разных текстур больше не перезаписывают друг друга);
- переработаны процедурные 3D-модели персонажей: связанный силуэт, сглаженные геометрические сегменты, более спокойные лица, натуральнее пропорции;
- ускорение, торможение, менее высокий прыжок, камера третьего лица через SpringArm;
- физические коллайдеры крупных столов;
- автоматический запуск локального сервиса MediaPipe при открытии хронологии, сохранение логов в `ai_service/camera_diagnostics.txt`;
- при отсутствии AI игра остаётся проходимой мышью, а NLP-классификатор допросов работает без камеры.

## Не подтверждено
- запуск Godot 4.7.2 на компьютере пользователя после этих изменений;
- корректность всех новых анимаций и отсутствие пересечений;
- распознавание на конкретной веб-камере Windows и наличие корректной модели;
- экспорт Windows exe и открытая публикация itch.io.

**Не выдавать эти функции за испытанные.** Следующий шаг — Godot F5, запуск проверок и полное прохождение экспортированной сборки.
