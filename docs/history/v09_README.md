# Тайны университета: Последняя пара — кампания v0.9

**Проверочная итерация, не финальный Ultimate-релиз.** Основана на v0.8.2,
а не на новом проекте. Все исходники изменённых файлов включены целиком.
Проверено в Godot 4.6.3 Linux headless; Windows, графический рендер и физическая камера
требуют ручной приёмки. Графика остаётся процедурной, без обещания коммерческого качества.

## Запуск
1. Распаковать ZIP целиком. Открыть `project/project.godot` в Godot 4.6.3 Standard.
2. Дождаться импорта ресурсов. Нажать **F5**.
3. Выбрать «Новая кампания» и сложность. Начало — университетский двор.
4. Улика находится слева, рабочая станция — справа. После целей идти к двери в конце карты.
5. AI-камера необязательна: вся кампания проходима мышью и клавиатурой без интернета.

## Управление
WASD/стрелки — ходьба; Shift — бег; Space — прыжок; мышь — обзор.
V — FPS/TPS; R — выровнять камеру; F — фонарик; E — взаимодействие.
Tab/J — журнал; P — телефон, цели и сопоставление; M — карта; K — магазин;
H — помощь; Esc — пауза и сохранение. В меню/диалоге управление мышью.

## Что добавлено
20 отдельных сцен, загружаемых по одной. 25 улик: все прежние 12 ID + 13 новых.
У каждой карты свой размер/окружение, цели, станция проверки и условие выхода.
Разные предметы: телефон, документы, аудиозаписи, терминалы, следы и носитель.
Станции в этой итерации преимущественно проверяют версии выбором ответа;
пространственные пазлы и более сложные манипуляции — следующий этап.
Три сложности; монеты за карты и достижения; 11 товаров без реальных платежей;
покупка/надевание, косметика модели, журнала, доски, света, скейт во дворе.
Карта прогресса, повтор завершённых уровней без изменения основного сохранения.
Четыре исхода дела; секретный эпилог выбирается отдельно в итоговом досье.

## Сохранения
Кампания: `user://campaign_v4.json`; предыдущая версия: `.bak`.
Профиль звука/эффектов/LLM: `user://detective_profile.json`.
Классика: прежний `user://last_class_case.json` — не перезаписывается кампанией.
На Windows каталог обычно `%APPDATA%/Godot/app_userdata/Тайны университета: Последняя пара/`.
Загрузка сохраняет цели и покупки, но ставит Алекса у безопасного входа карты.
Меню «Импортировать улики v0.8.2» переносит факты и XP; новая кампания начинается
с карты 1, поскольку старые главы не доказывают прохождение новых заданий.
Повтор запускается через M; выйти из повтора можно там же. Награды не дублируются.
Новая кампания сбрасывает кошелёк и покупки, сохраняя настройки звука.

## AI
NLP: прежний обучаемый Naive Bayes-классификатор русских вопросов.
Вопросы своими словами меняют ветки диалога и сюжетные флаги.
Ollama необязательна: в кампании модель выбирает тон из разрешённых реплик.
Произвольный текст модели не используется как факт. Это сознательное ограничение
генерации, чтобы она не раскрывала сюжет и не придумывала доказательства.
Сканер — игровая симуляция, не отдельная нейросеть.
MediaPipe — реальный распознаватель по OpenCV-кадрам; тест камеры не выполнен здесь.

## Подготовка камеры (один раз, до игры)
Запустить `SETUP_CAMERA_WINDOWS.bat` при наличии Python и интернета.
Он устанавливает зависимости и скачивает модель. В игре установки/скачивания нет.
Запустить `VALIDATE_REAL_CAMERA_WINDOWS.bat`: показать четыре жеста, затем убрать руку.
Результат сохраняется в `ai_service/real_camera_acceptance.json`.
Закрыть окно камеры перед запуском игрового сервиса, иначе устройство может быть занято.
На карте 19 сервис запускается автоматически; ошибки — в `ai_service/camera_diagnostics.txt`.
Жесты выбирают строки оставшегося списка: кулак=1, два пальца=2, ладонь=3, лайк=4.
Событий пять; после первого выбора остаётся четыре. Канонический первый пункт доступен
жестами сразу. Неверный порядок можно повторить без штрафа к доступности игры.

## Проверки
`RUN_CAMPAIGN_TESTS.bat` (Godot в PATH или переменная GODOT_EXE).
Тесты используют временный каталог сохранений. Подробности: `tests/LAST_RUN.json`,
`docs/TEST_REPORT.md`. Ручная приёмка Windows: `docs/WINDOWS_ACCEPTANCE.md`.

## Экспорт Windows
Godot: Project → Export → Manage Export Templates, установить шаблоны **той же версии**.
Выбрать Windows Desktop → Export Project → `dist/Tayny_Universiteta.exe`.
Или запустить `EXPORT_WINDOWS.bat`. Отдать пользователю всю папку `dist`, включая
`.pck` (если создан), `ai_service` и BAT-файлы подготовки/запуска камеры.
Windows EXE в этой поставке не собран и не протестирован.
