# v0.9 — кампания, 13 ноября 2026

- Сохранён исходный проект и отдельный классический режим.
- Добавлены Catalog, CaseState, LevelManager, CampaignMap/Controller и 20 сцен.
- Добавлены 13 улик, цели, карта, задания, кошелёк, магазин и replay.
- Сохранения v4 с backup, отдельный профиль, импорт старых фактов без изменения старого файла.
- Хронология включает 21:22. Досье проверяет пять элементов обвинения.
- Автоустановка AI вынесена в отдельную подготовку; модель загружается из bytes
  для исключения передачи кириллического пути в нативный MediaPipe API.
- Генерация в кампании ограничена разрешёнными репликами. Классика сохранена.
- Добавлены изолированные runtime-тесты и сценарий проверки реальных кадров.

## v0.7 — Исправление визуала и диагностики жестов (исходники, не проверенная Windows-сборка)

**По скриншоту пользователя:**
- Исправлена причина вида «сплошных коричневых шкафов»: убран большой непрозрачный блок из каждого книжного стеллажа; теперь корпус состоит из боковин, отдельных полок, задней панели и книжных корешков.
- Полки библиотеки расставлены с более широкими проходами; восстановлена читаемость столов и зоны поиска.
- Заменены четыре почти чёрные грязные текстуры полов на светлые деревянные и каменно-плиточные покрытия; убраны накладные бирюзовые линии отладки.
- Стены, потолок, туман и освещение переведены в спокойную естественную палитру.
- Третье лицо: камера ближе к герою, меньший наклон вниз, новый сброс `R`, исключение коллайдера героя из SpringArm.
- Исправлены «парящие» примеры предметов: электрощит на стене, сканер на рабочей поверхности, сломанный стеллаж на полу; следовательские стенды имеют ноги.
- Оптимизировано повторное использование материалов для множества книг и объектов.

**Распознавание жестов:**
- Добавлена диагностическая программа с перебором реальных камер и backend Windows, выдающая текстовый отчёт.
- Обновлена версия MediaPipe до 1.2.2+ для Python 3.13; проверка кадра до запуска модели.
- При ошибке камера больше не притворяется рабочей: выводится диагностическая ошибка. Ручной fallback доступен отдельным батником и обозначен как НЕ AI.
- Стабильное переключение между разными жестами без обязательного удаления руки из кадра.
- Игра показывает источник событий — настоящая веб-камера или ручной резерв.

**Что не подтверждено:** Godot GUI/Windows-запуск, качество веб-камеры на пользовательском оборудовании, полный регресс прохождения v0.7. Готовых лицензированных высокодетализированных 3D-моделей персонажей в этой версии нет.
