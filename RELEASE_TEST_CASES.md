## Дополнительное AI-тестирование

Отдельно оценить ошибки классификатора по 10–20 заранее записанным вопросам: правильная тема / неправильная тема; процент правильных; ситуации неоднозначных вопросов. Жесты проверить при хорошем и слабом освещении, для разных рук и при отсутствии руки. **Результаты не придуманы заранее.**
