# Проверка v0.11.2 · 13 ноября 2026

Исходная версия взята из рабочей папки Desktop/project с патчем v0.11.1.
В проекте 20 сцен уровней и 19 самостоятельных экспертиз. Уровни 7 и 13
получили свободный подход к свидетелям после переноса столов экспертизы.

## Голос на Windows

С Vosk 0.3.45 оригинальная ошибка воспроизведена на абсолютном пути с
«Ерасыл». По относительному пути те же файлы открылись. Теперь Python
переходит в папку модели средствами Windows с поддержкой Unicode и
передаёт Vosk относительный путь. Установщик проверяет 13 файлов модели
и создаёт распознаватель до вывода SUCCESS. Проверены чистая распаковка
официального ZIP, восстановление после обнуления файла и двойная вложенность.
Оба BAT-скрипта проверены на Windows. Для проверки модели без оборудования
выполни CHECK_VOICE_WINDOWS.bat --model-only.

## Запуск

В Windows-сборке распакуй весь архив и открой Tayny_Universiteta.exe.
Для разработки импортируй project.godot в Godot 4.7.2. Для голоса запусти
SETUP_VOICE_WINDOWS.bat, затем CHECK_VOICE_WINDOWS.bat и произнеси вопрос.
Для камеры используй SETUP_CAMERA_WINDOWS.bat и VALIDATE_REAL_CAMERA_WINDOWS.bat.

Физический микрофон и веб-камера, визуальное прохождение и запуск на другом
ПК не проверялись. Для методички №8–15 проверены функциональные сценарии,
сохранения и автоматические сценарии AI. Проверка AI с оборудованием,
командная история в закрытом GitHub и приёмка коммерческой модели требуют
отдельных подтверждений. Магазин проверен для игровой валюты.
