# University Secrets: The Last Class

**«Тайны университета: Последняя пара»** — 3D-детектив на Godot 4 для IT Project Game Challenge 2026.

**20 игровых карт:** исследование помещений, сбор улик, реконструкция событий, допросы персонажей, три сложности, сохранения и косметический магазин за игровые монеты. AI: локальный классификатор смыслов вопросов (NLP), дополнительные веб-камера/MediaPipe и голосовые вопросы/Vosk.

**Команда ИС-44:** **Муталип Ерасыл** — руководитель, основной разработчик и AI-интегратор; **Мухит Меруерт** — сценарное направление, визуальный дизайн, QA. Подробнее: [TEAM.md](TEAM.md).

> **Это архив исходного кода, не Windows-игра для игроков.** Для бесплатного запуска скачайте Windows `.exe`-релиз со страницы itch.io после его публикации. Для проверки исходников нужен Godot 4 и, для дополнительных функций, настройка Python/AI-сервисов. Реальные платежи в магазине отсутствуют.

# Тайны университета: Последняя пара — v0.11.3 (кампания из 20 карт)

Для камеры сначала запусти `SETUP_CAMERA_WINDOWS.bat`, затем
`CHECK_CAMERA_WINDOWS.bat`. Закрыть предпросмотр можно клавишей Q или Esc.
Команда `CHECK_CAMERA_WINDOWS.bat --model-only` проверяет MediaPipe без камеры.
В игре камера подключается у реконструкции на уровне 19.
Подробности проверки камеры — в `VERIFICATION_v0_11_3.md`.

Для голоса нужен Python 3.11 или новее в PATH. Запусти `SETUP_VOICE_WINDOWS.bat`.
Проверка модели без микрофона: `CHECK_VOICE_WINDOWS.bat --model-only`.
Для живой проверки запусти `CHECK_VOICE_WINDOWS.bat` и произнеси вопрос по-русски.
Результат успешной проверки содержит `"ok": true`, распознанный текст и имя движка.
См. `VERIFICATION_v0_11_2.md` для результатов автоматических тестов и запуска.

**Проверочная версия для Windows / Godot 4.x, основанная на рабочей v0.10, не новый проект.**
Сохранены сюжет, сцены всех 20 уровней, Алекс и NPC, две камеры, управление,
уже существующие улики, допросы/NLP, магазин за игровые монеты, три сложности,
сохранения и концовки.

## Новое в v0.11

- Главный экран снова показывает **университет** из оригинального `assets/ui/menu_art.png`.
- Убраны только две кнопки: «Импортировать улики v0.8.2» и «Классический режим».
  Соответствующие старые файлы не удалены, чтобы не ломать совместимость.
- **Магазин** открыт из главного меню; монеты, приобретения и одетые предметы
  читаются из существующего сохранения. Есть косметика за монеты и демонстрационные
  образы по ценам 399 ₸ / 690 ₸ / 1090 ₸. **Настоящих платежей нет, эти образы
  невозможно купить за деньги.**
- Картам 2–20 добавлены **19 разных сюжетных экспертиз** с тремя способами решения:
  последовательности, логические сопоставления, коды. Есть объяснение неверных
  решений, учёт ошибок и сохранение пройденных экспертиз. 11-я карта специально
  защищена от взаимной блокировки заданий.
- Вместо всех улик слева предметы разбросаны по разным безопасным участкам карт;
  добавлены отдельные физические столы экспертизы. Уже созданные комнаты сохранены.
- На 19-й карте работают пять жестов: 1 — кулак, 2 — победа, 3 — ладонь, 4 — лайк,
  **5 — указательный палец вверх (Pointing_Up)**. Распознаватель запускается
  автоматически по `E` возле реконструкции. Кадры могут показываться прямо на
  экране задания; отдельное CMD при автоматическом запуске не требуется при
  наличии Python Launcher `pyw.exe`. Веб-камера после краткого обрыва пробует
  подключиться повторно. При первом старте может потребоваться интернет для
  установки MediaPipe и скачивания модели; ошибки — в журнале.
- Русские **голосовые вопросы** Руслану, Мире и Данияру через кнопку 🎤 в допросе.
  Используется локальная Vosk-модель (после установки) или доступный русскоязычный
  распознаватель Windows. Результат передаётся существующему NLP, **не является
  заранее заготовленным вопросом**. Аудио не записывается на диск и не
  отправляется в облако. Текстовый ввод остаётся доступным.

## Запуск из исходников

1. Распакуйте весь ZIP в отдельную папку (содержит `project.godot`).
2. Откройте `project.godot` в Godot 4.7.2 или другом совместимом Godot 4.x;
   дождитесь импорта ассетов, нажмите `F5`.
3. `Новая кампания` — выбор сложности; `Продолжить кампанию` — прежний слот;
   `Магазин` — покупки за монеты **до** начала игры или по клавише `K`.
4. `WASD` — движение; `Shift` — бег; `Space` — прыжок; `E` — действие; `V` —
   смена камеры; `R` — сброс; `F` — фонарик; `Tab` — улики; `P` — телефон;
   `M` — карты; `H` — подсказки; `Esc` — пауза.
5. На уровнях 2–20 сначала найдите обязательные улики, затем стол `ЭКСПЕРТИЗА`,
   потом рабочую станцию. Неправильные действия объясняются. На 11-м уровне код
   хранилища можно разгадать до получения запертой флешки.
6. На уровне 19 нажмите `E` у реконструкции: запустится камера (если Python и
   камера доступны). Все пять пунктов также управляются мышью.

## Настройка реальной камеры

Для **автоматического старта в задании** должен быть установлен Python 3 с
`pyw.exe` или `py.exe`. Игра теперь пытается сама установить отсутствующие
OpenCV/MediaPipe и скачать `gesture_recognizer.task` в **фоновом процессе** при
первом использовании. Для этой разовой подготовки нужны интернет и права на
запись в папку с игрой. Она может не пройти из-за доступа, антивируса,
версии Python или ошибки сети. Тогда один раз запустите `SETUP_CAMERA_WINDOWS.bat`
и проверьте `CHECK_CAMERA_WINDOWS.bat` или `VALIDATE_REAL_CAMERA_WINDOWS.bat`.
Полный журнал: `ai_service/camera_diagnostics.txt`.

Сервис не запускает резервный ручной режим под видом ML. В кадре на задании
должен показываться настоящий видеопоток и статус **ready**.
По реальной веб-камере проверки должны выполняться непосредственно на Windows.

## Голосовой допрос

В диалоге с Русланом, Данияром или Мирой нажмите `🎤` и произнесите один вопрос
на русском. Сперва пробуется установленная модель Vosk (офлайн); иначе Windows
Speech Recognition `ru-RU`, если доступен в системе. Если Windows не имеет
русского распознавателя, **один раз запустите `SETUP_VOICE_WINDOWS.bat`**:
устанавливаются `vosk`, `sounddevice` и русская модель (~45 МБ).
Проверка: `CHECK_VOICE_WINDOWS.bat`. При отсутствии микрофона/модели можно
написать вопрос вручную. Запись голоса не сохраняется в игре.

## Монетизация

Основные 20 карт и истинная концовка бесплатны. Скины и косметика приобретаются
за монеты, которые зарабатываются расследованием, и сохраняются в существующем
слоте. Образы по ценам 399/690/1090 ₸ — **только макет коммерциализации**:
здесь нет платёжной системы, обработки карты или выдачи лицензии.

## Проверки и ограничения

Статическая проверка структуры и Python-тесты не подтверждают, что Godot
компилирует новые GDScript-файлы, что все 20 уровней проходимы после правок
или что пользовательская камера и микрофон работают. Этот ZIP содержит
**исходники Godot, не проверенный Windows EXE**.

Для теста на Windows: запустите проект в Godot, пройдите уровень 1, новый уровень 2,
код и флешку на уровне 11, пять жестов на уровне 19 и правильную концовку на 20.
См. `docs/WINDOWS_ACCEPTANCE_V11.md`.

Стандартное сохранение: `user://campaign_v4.json`. Старое сохранение не удаляется.
Снимите резервную копию папки `user://` перед тестом на случай неожиданной ошибки.
