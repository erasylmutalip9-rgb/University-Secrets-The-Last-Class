# v0.11.1 — Исправление голосового допроса

## Что произошло

В Windows PowerShell 5.1 файл `ai_service/voice_windows.ps1` был записан в UTF-8 без BOM и содержал кириллицу. PowerShell 5.1 интерпретировал текст в системной ANSI-кодировке, поэтому ломалась строка ошибки, возникали `ParserError` и `UnexpectedToken`. Скриншот показывает именно это.

## Что исправлено

- `ai_service/voice_windows.ps1` теперь использует только ASCII в исходном коде и записывает UTF-8 JSON явно. Ошибка кодировки больше не должна вызывать синтаксическую ошибку.
- Скрипт проверяет наличие установленного русскоязычного распознавателя Windows. При его отсутствии сообщает об этом без технического стека.
- `ai_service/voice_service.py` сначала пытается распознать вопрос офлайн через Vosk, если модель установлена; в противном случае использует Windows Speech. Если оба источника недоступны, возвращает короткую инструкцию по установке Vosk, а не повреждённый текст.
- Vosk использует частоту записи, которую реально поддерживает микрофон, вместо принудительных 16 кГц.
- `ai_service/voice_diagnostics.txt` создаётся при попытке распознавания, но не записывает произнесённые слова и аудиофайл.
- `CHECK_VOICE_WINDOWS.bat` выводит результат проверки в читаемом виде.

## Установка поверх v0.11

1. Закрой Godot и игру.
2. Распакуй маленький ZIP-патч в папку, где находится `project.godot`, с заменой файлов (`ai_service` должна находиться рядом с `project.godot`).
3. Один раз запусти `SETUP_VOICE_WINDOWS.bat` (нужен интернет). Дождись `SUCCESS`.
4. Запусти `CHECK_VOICE_WINDOWS.bat` и скажи по-русски один вопрос. Ожидается `"ok": true` и не пустое поле `text`.
5. Запусти Godot и нажми кнопку «Сказать вопрос» в разговоре с Русланом, Мирой или Данияром.

Если тест не прошёл, пришли `ai_service/voice_diagnostics.txt` и текст из окна установки. Без русского распознавателя Windows и без установленной офлайн-модели Vosk реального распознавания речи нет; текстовые вопросы доступны независимо от этого.

## Проверка

Python-файлы проверены компилятором и модульными тестами. Windows PowerShell, физический микрофон и Godot в этой среде недоступны: их работу следует проверить на Windows. Никакие изменения сюжета, меню, 20 карт, улик, магазина или сохранений не вносились.
