# Тайны университета: Последняя пара

**Трёхмерное детективное приключение с элементами психологического хоррора и AI-допросами.** В университетском корпусе погибает профессор, работавший над секретным исследованием «ЭХО». Студент Алекс осматривает библиотеку, лабораторию и архив, находит улики и сопоставляет показания трёх подозреваемых. Играть можно от первого и третьего лица.

**Разработчики:** Мухит Меруерт, Муталип Ерасыл — группа **ИС-44**.

**AI-технология:** локальная обучаемая NLP-модель (Multinomial Naive Bayes) классифицирует свободные текстовые вопросы в AI-допросах: алиби, пропуск/доступ, камеры, проект, улики. Категория вопроса влияет на реплики NPC и доступные противоречия. Дополнительное экспериментальное подключение генеративных ответов через Ollama (не обязательно для игры).

**Управление:** WASD — ходьба; мышь — обзор; Shift — бег; E — взаимодействие; V — первое/третье лицо; R — сброс камеры; F — фонарь; Tab/J — журнал улик; Esc — пауза.

**Бесплатная игра:** весь контент можно открыть через демонстрационную кнопку «Разблокировать полную игру (демо)» после первого этапа, без оплаты и регистрации.

**Технические требования:** Windows x64. Скачайте ZIP, распакуйте его целиком и запустите `.exe`. Для основного прохождения экспортированной игры Godot и Python не нужны; дополнительный режим MediaPipe с веб-камерой требует Python и отдельного сервиса.

**Исходный код:** [вставить настоящую ссылку на GitHub после публикации].

**Предупреждение:** в игре присутствуют внезапные звуки и визуальные хоррор-эпизоды; скримеры можно отключить в настройках. Голосовое управление и распознавание физических карточек пока не реализованы; внутриигровой сканер улик является виртуальной механикой. Распознавание жестов через веб-камеру работает только при запуске отдельного MediaPipe-сервиса и требует проверки на вашем устройстве.

**Обновление v0.7:** теперь есть встроенный инструктаж, прыжок на Space, открываемые шкафы и различающиеся 3D-предметы. Для проверяющих доступно локальное NLP-распознавание вопроса без интернета. Экспериментальное распознавание четырёх жестов через MediaPipe требует отдельного Python-модуля с моделью и не встроено автоматически в обычный EXE.

Для диагностики отдельного жестового модуля см. `GESTURES_SETUP.md`; клавиатурная имитация не является AI.
