# Управление настоящей камерой / MediaPipe / v0.11

**На уровне 19 подойти к реконструкции и нажать E.** Игра попытается сразу
включить MediaPipe в фоновом процессе `pyw.exe`, без отдельного окна CMD.
При первом запуске (если библиотек/модели ещё нет) Python попытается один раз
установить зависимости и скачать модель. Нужен интернет.

Жесты для пяти строк списка:
1. Closed_Fist — кулак.
2. Victory — два пальца.
3. Open_Palm — открытая ладонь.
4. Thumb_Up — лайк.
5. Pointing_Up — указательный палец вверх.

Состояние и кадры показываются в окне задания. Если камера недоступна,
мышь работает всегда. Кнопка «Повторно подключить AI-камеру» на стенде
позволяет повторить попытку. После кратковременной потери кадров сервис
переподключается к индексам 0, 1, 2.

Если не работает: запустите `SETUP_CAMERA_WINDOWS.bat`, затем
`CHECK_CAMERA_WINDOWS.bat`; проверьте разрешения Windows и закройте программы,
занявшие камеру. Полный лог: `ai_service/camera_diagnostics.txt`.

Проверка настоящих кадров и пяти жестов: `VALIDATE_REAL_CAMERA_WINDOWS.bat`.
Это нельзя заменить вводом цифр: он является только ручным резервом.
