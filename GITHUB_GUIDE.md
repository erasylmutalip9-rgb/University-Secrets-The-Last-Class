# Как выложить исходный код на GitHub и показать преподавателю

1. Создайте новый GitHub-репозиторий, например `university-last-class`. Сначала **Private** согласно методичке лабораторных №8–15, пригласите обоих участников и преподавателя.
2. Перетащите файлы проекта/сделайте `git init`, `git add .`, `git commit -m "RK2 3D project: collision fixes and offline AI NLP"`, затем настройте `remote` и `git push`.
3. Не добавляйте `.godot/`, `dist/`, `.exe`, `.pck`, личные ключи/токены, логи тестов (см. `.gitignore`).
4. В README укажите: **Мухит Меруерт и Муталип Ерасыл, ИС-44**, ссылку itch.io, описание AI, управление и запуск.
5. Коммиты обоих студентов должны отражать **реальную работу**: сцены/дизайн/диалоги и AI/физика/сборка. Не создавайте ложные коммиты на имя партнёра.
6. Для РК2 преподаватель требует ссылку GitHub. **Private** ссылка не откроется публичному тестировщику; если нужна публичная доступность, согласуйте с преподавателем, сделать ли исходный репозиторий **Public** или отдельный публичный релизный репозиторий. Нельзя одновременно выполнить требование приватности методички и общедоступности исходников по одной ссылке без дополнительных прав.

## Как показать код на защите

- Откройте проект в Godot через Import → `project.godot`.
- FileSystem → `scripts/player.gd`: покажите CharacterBody3D, коллизию, физику и смену камеры.
- `scripts/world_builder.gd`: покажите геометрию и StaticBody3D, соединительные мосты.
- `scripts/intent_classifier.gd`: покажите обучающие примеры, вероятностный расчёт, результат классификации.
- `scripts/game.gd`: покажите, как классификатор меняет диалог и как начисляются очки/открывается глава.
- Запустите `RUN_RK2_TESTS.bat` для отчёта (если установлены экспортные шаблоны и редактор в PATH). Покажите Game / Output / Debugger, затем историю GitHub-коммитов.
